B27

CVNSS4.0 · Base27 · Balanced ternary · Lossless

Mã nguồn GitHub · Kiểm định CI · Rust/WASM Web Studio

Kiến trúc

UTF-8 → kiểm tra CVNSS thuận nghịch theo âm tiết → Base27 (5 ký hiệu / 3 byte) hoặc ASCII → DEFLATE → B27F + SHA-256. Dữ liệu không thuận nghịch được giữ nguyên. Auto chọn payload nhỏ nhất, kể cả raw.

Đây chưa phải LZ27/Range27 độc lập. Không khẳng định vượt LZMA trước khi có benchmark corpus độc lập.

Cài đặt và sử dụng

git clone https://github.com/xulytiengviet/B27.git
cd B27
node b27.cjs c input.txt input.b27
node b27.cjs d input.b27 restored.txt
node test.cjs
node test.cjs corpus.txt

Node.js 22; không cần npm. Giới hạn đầu vào 16 MiB. File đích phải chưa tồn tại.

Kiểm định tái lập

Đối chiếu byte-for-byte, audit converter, kiểm tra dữ liệu hỏng, đo kích thước và thời gian trung vị. Kết quả CI chỉ xác nhận các mẫu đã kiểm tra. Mục tiêu hiệu năng cần corpus tiếng Việt độc lập và đối chứng LZMA.
